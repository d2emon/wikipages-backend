# Добро пожаловать в вики

Этот сервис хранит заметки в формате Markdown. Каждая заметка — отдельный
файл `.md` в томе `wiki_data`.

## Как читать

- `/wiki/memo/Добро пожаловать.md` — исходный Markdown.
- `/wiki/memo/Добро пожаловать.html` — отрендеренная HTML-страница.
- `/wiki/` — список всех доступных заметок.

## Как писать

Добавление, редактирование и удаление выполняются через API с ключом
`WIKI_API_KEY`. Примеры команд есть в README проекта.

## Разметка

Поддерживаются заголовки, списки, таблицы, ссылки, изображения и блоки кода.

```bash
curl -H "Authorization: Bearer $WIKI_API_KEY" \
  "http://localhost:8080/api/notes/memo/Example"
```
